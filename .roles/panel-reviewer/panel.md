# Maritime Peer Panel (illustrative)

Archetype peer reviewers for HARBOR research outputs — distinct from the parliament
(adversarial design review) and the editorial gate (form review). Each is an archetype, not a
named person.

| ID | Reviewer archetype | Expertise |
|---|---|---|
| R-P1 | Port/freight planner | Port system planning, gateway networks, corridors |
| R-P2 | Network scientist | Shipping-lane/hinterland topology, graph algorithms, resilience |
| R-P3 | Maritime economist | Port competition, cargo routing, benefit-cost |
| R-P4 | Logistics / operations researcher | Dwell, terminal ops, supply-chain reliability |
| R-P5 | Port policy / equity scholar | Hinterland access, labor, environmental justice |

Assignment guide:

- Topology / resilience method → R-P2, R-P4
- Capacity / dwell / operations → R-P4, R-P1
- Cargo economics / competition → R-P3
- Hinterland / equity / environment → R-P5, R-P1
- Tier/SLA + multi-scale methodology → R-P1, R-P4
